# 📊 Festival da Costela — Data Analytics & ETL

Projeto de análise de dados desenvolvido a partir de avaliações coletadas durante o Festival da Costela.

O objetivo do projeto é transformar respostas de uma pesquisa em informações estruturadas que possam auxiliar na compreensão do perfil dos participantes, comportamento dos visitantes, potencial de consumo, fidelidade e intenção de retorno.

O projeto utiliza um fluxo de **ETL (Extract, Transform, Load)** desenvolvido em Python, com preparação dos dados para análise e visualização em Power BI.

---

## 🎯 Objetivos

- Organizar e tratar os dados coletados na pesquisa;
- Realizar um processo de ETL utilizando Python e Pandas;
- Criar perfis comportamentais dos participantes;
- Identificar padrões de fidelidade e intenção de retorno;
- Classificar potencial de consumo;
- Avaliar o nível de engajamento dos participantes;
- Preparar os dados para visualização em Power BI;
- Demonstrar como dados de pesquisas podem gerar insights para eventos.
